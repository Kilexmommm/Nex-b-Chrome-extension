## Prompts utilizados

### Aurora

Use case: stylized-concept. Asset type: desktop dashboard wallpaper for a browser extension, landscape 16:9. Create a beautiful restrained photographic-style aurora borealis over distant mountains and a still lake at blue hour. Deep midnight navy, muted emerald and violet glow. Quiet composition, low detail and low contrast across upper two thirds where UI will appear; landscape silhouettes low near bottom edge. Premium calm natural atmosphere, not neon, no text, no letters, no logo, no UI, no border. Full bleed wallpaper.

### Dunas

Use case: photorealistic-natural. Asset type: desktop dashboard wallpaper for a browser extension, landscape 16:9. Create a beautiful minimal fine-art photograph of rolling desert sand dunes in soft early morning light, pale ivory sky, warm sand, muted peach and terracotta shadows. Large quiet areas, softly layered graceful dune ridges predominantly in lower half, gentle contrast to allow readable interface over it. No people, no buildings, no vegetation, no text, no logo, no UI, no border. Full bleed wallpaper.
